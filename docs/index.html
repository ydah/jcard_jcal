vCard ↔ jCard / iCalendar ↔ jCal

Convert contact and calendar formats in Ruby

Convert vCard 4.0 and iCalendar text to and from jCard and jCal. Handle structured values, nested calendar components, escaping, and line folding through a Ruby API.

Get started Read the documentation

Ruby 3.3+MIT licenseRubyGems

  • Convert both ways

    Read text or JSON and serialize contact cards and nested calendar components in either form.

  • Keep extensions

    Preserve unknown properties and use custom registries for application-specific value types.

  • Handle text details

    Apply parameter escaping and UTF-8-safe line folding with bounded parsing and validation.

Installation

Add the gem to your Gemfile:

gem "jcard_jcal"

Run bundle install, then try the quick start. Requires Ruby 3.3 or later.

For supported dependencies and optional integrations, see the installation guide.

Scope & documentation

vCard support is limited to version 4.0. Calendar semantic rules, time zone conversion, recurrence expansion, and CardDAV/CalDAV transport are outside scope. Text serialization normalizes equivalent representations rather than preserving identical bytes.

Read the full documentation for supported formats, examples, and API details.
